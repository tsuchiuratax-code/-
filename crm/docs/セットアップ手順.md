# 林税理士社労士事務所 CRM セットアップ手順

## システム構成

```
Google Spreadsheet（データベース）
    ├── 顧客マスタ
    ├── 契約情報
    ├── 面談履歴
    ├── 事務所通信
    ├── メール配信ログ
    └── 設定

Google Apps Script（バックエンド + Webアプリ）
    ├── Config.gs           設定・共通関数
    ├── Setup.gs            初回セットアップ
    ├── CustomerService.gs  顧客CRUD
    ├── CalendarService.gs  Googleカレンダー連携
    ├── NewsletterService.gs メール配信・事務所通信
    ├── ImportService.gs    データインポート
    ├── WebApp.gs           WebアプリURL処理
    ├── index.html          メイン画面
    ├── style.html          スタイル
    └── script.html         JavaScript
```

---

## ステップ1：Googleスプレッドシートを作成する

1. Google ドライブを開く → 「新規」→「Googleスプレッドシート」
2. シート名を **「林税理士CRM」** に変更する
3. URLから **スプレッドシートID** をコピーしておく
   - 例：`https://docs.google.com/spreadsheets/d/【ここがID】/edit`

---

## ステップ2：Google Apps Scriptを設定する

1. スプレッドシートのメニュー → **「拡張機能」→「Apps Script」** を開く
2. 左側の「ファイル」から各`.gs`ファイルを追加してコードを貼り付ける
3. `index.html`、`style.html`、`script.html` もHTMLファイルとして追加する
4. `appsscript.json` を上書き保存する（詳細設定を表示してから編集）

---

## ステップ3：初回セットアップを実行する

GASエディタのエディタ画面で：

```
関数を選択：setupSpreadsheet → 実行
```

これにより、スプレッドシートに必要な全シートが自動作成されます。

---

## ステップ4：既存顧客データを取り込む

### 顧問先一覧.xls を取り込む

1. スプレッドシートに「顧問先一覧」という名前のシートを作成する
2. Excelファイルの内容をそのシートにコピー貼り付け
3. GASエディタで `importCustomersFromSheet()` を実行

ヘッダー名は以下のキーワードを含んでいれば自動認識します：
| 列の内容 | 認識されるキーワード |
|---|---|
| 法人名/氏名 | 法人名、氏名、顧客名、名前、会社名 |
| メール | メール、mail、email |
| 電話 | 電話、TEL |
| 契約種別 | 契約種別、契約区分、契約 |
| 決算期 | 決算期、決算月 |
| 顧問料 | 顧問料、月額報酬、月次報酬 |

### メールアドレス一覧.xlsm を取り込む

1. スプレッドシートに「メールアドレス一覧」シートを追加して内容を貼り付け
2. GASエディタで `mergeEmailAddresses()` を実行

### 報酬CSV（syukei-hosyu-furikae）を取り込む

1. CSVファイルをGoogleドライブにアップロードする
2. ファイルのリンクからIDをコピー
3. GASエディタで以下を実行：

```javascript
importFeeFromCsv('【ファイルID】');
```

---

## ステップ5：Webアプリとしてデプロイする

1. GASエディタ → 「デプロイ」→「新しいデプロイ」
2. 種類：**「Webアプリ」** を選択
3. 設定：
   - 説明：「林税理士CRM v1.0」
   - 次のユーザーとして実行：**「自分（〇〇@gmail.com）」**
   - アクセスできるユーザー：**「自分のみ」**（セキュリティのため）
4. 「デプロイ」をクリック → URLをコピーして保存

---

## ステップ6：Googleカレンダー連携を設定する

1. [Google Calendar](https://calendar.google.com) を開く
2. 使用するカレンダーの「設定と共有」→「カレンダーのID」をコピー
3. GASエディタで実行：

```javascript
PropertiesService.getScriptProperties().setProperty('CALENDAR_ID', 'your-calendar-id@group.calendar.google.com');
```

## 主な機能の使い方

### 顧客の登録
1. CRMを開く → 「顧客管理」タブ
2. 「＋ 新規登録」ボタン
3. 必須項目（法人名・契約種別）を入力して「保存」

### 事務所通信の配信
1. 「事務所通信」タブ → 「＋ 新規作成」
2. タイトル・配信対象・本文を入力
3. 「保存して配信」をクリック
4. 顧客のメールアドレスに自動送信される

### Googleカレンダーへの期限登録
1. 「カレンダー連携」タブ
2. 「申告期限を一括登録」ボタン
3. 全顧客の決算・申告期限がGoogleカレンダーに登録される

## よくある質問

**Q: メールが届かない**
A: GmailのAPIには1日500通の制限があります。顧客が多い場合は複数回に分けて配信してください。

**Q: 顧客名が合わなくてインポートできない**
A: Excelの顧客名がCRMと部分一致すれば自動マッチングします。全角・半角の違いに注意してください。

**Q: カレンダーに登録されない**
A: GASの権限承認が必要です。初回実行時に「Googleカレンダーへのアクセスを許可」してください。
