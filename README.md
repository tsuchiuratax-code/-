# ChatGPT 5 改良点比較スライド（Claude比較）

昨日の続きとして、**ChatGPT 5 の改良点を Claude と比較するためのスライド型Webページ**です。

## 概要

- 6枚構成のスライドUI
- 「系図図解（genealogy diagram）」で進化ポイントを視覚化
- 実務ユースケース別の比較表
- 日本語 / 英語のリアルタイム切り替え
- キーボード操作（← / →）対応

## ファイル構成

```
.
├── index.html          # スライド本体（6セクション）
├── src/
│   ├── style.css       # スライドレイアウトと図解スタイル
│   ├── i18n.js         # 国際化ロジック
│   └── app.js          # スライド遷移ロジック
├── locales/
│   ├── ja.js           # 日本語文言
│   └── en.js           # 英語文言
└── README.md
```

## 使い方

1. `index.html` をブラウザで開く
2. 上部の `前へ / 次へ` ボタン、またはキーボード `← / →` でスライド移動
3. `日本語 / English` ボタンで言語切り替え

## 補足

この資料は**説明用の比較テンプレート**です。実運用では、同一条件の検証データ（速度、品質、編集工数）を加えて更新することを想定しています。
